## Result Snapshot

Lower MAE is better. The reported mean normalized MAE values are:

| Model or ensemble | Mean normalized MAE |
| --- | ---: |
| Traditional-only ensemble | 0.08740 |
| XGBoost | 0.09434 |
| Released fine-tuned MIST checkpoint | 0.09506 |
| MLP | 0.10036 |
| Engineered Ridge | 0.14984 |
| Supplemental all-model ensemble | 0.08116 |

The main comparison keeps the traditional-only ensemble separate from MIST. The
all-model ensemble is reported only as a supplemental second layer. The measured
36.4-minute runtime belongs to the local comparison pipeline; it is not the MIST
pretraining or fine-tuning time.

## Scientific Scope and Attribution

- The University of Michigan team developed, pretrained, fine-tuned, and
  released the MIST checkpoint.
- Lu Zhang independently built the benchmark workflow, trained the comparator
  models, evaluated the released checkpoint, analyzed the results, and authored
  the SciencesLoop case study.
- The current evidence comes from a fixed candidate split. It does not yet
  support a causal claim about the benefit of pretraining or fine-tuning.
- The planned five-seed protocol has not yet been run for MIST and should not be
  described as completed.
