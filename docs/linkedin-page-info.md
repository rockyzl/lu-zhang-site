## Description / About — English (Overview field)
```
SciencesLoop builds AI agents for scientific work — systems that retrieve evidence, plan the next step, and leave a trace someone can inspect.

The premise is simple: scientific work rarely fails for lack of an answer. It fails when the path from question to evidence to decision is unclear. SciencesLoop treats AI for Science as a workflow problem — retrieval, tool use, evaluation, and human review — not another chat interface.

The work sits where deep battery and materials research meets practical AI engineering: RAG over scientific corpora, agent evaluation, MLOps, and traceable decision support for researchers and engineers.

Founded and run by Lu Zhang, a former Argonne National Laboratory scientist now working in applied AI/ML.

Explore the public agent and working notes at sciencesloop.com.
```
