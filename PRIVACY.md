# Privacy & disclosure policy

This repo is the source for a public personal-academic site at
<https://rockyzl.github.io/lu-zhang-site/>. It is intentionally
public so search engines and visitors can discover the site.

## What this repo / site exposes

Only information that already exists in public form elsewhere:

- Name (Lu Zhang / 张鲁) and the company contact email (`luzhang@sciencesloop.com`)
- Education and career history (already on LinkedIn / OpenAlex / ANL profile)
- Peer-reviewed publications (already in OpenAlex / Crossref / Google Scholar)
- US patents (already on USPTO / Google Patents / OSTI)
- DOE-funded projects (already in DOE / Argonne press releases)
- Public press mentions (already published by the linked outlets)
- Co-author network (derived from already-public OpenAlex records)

## What this repo / site never exposes

The following stay in a separate, private data repo and never get
committed here:

- Date of birth, passport number, government ID numbers
- Home address, phone number, family info
- Salary / tax / social-insurance records
- Original employment-verification letters
- Scanned ID / passport / certificate documents
- Any application-package working materials
- Work-issued email accounts
- Internal proposals, draft chapters, peer-review correspondence

## For contributors / forkers

If you fork or contribute, do not commit:

- Files larger than a thumbnail-quality JPEG
- Any document that contains a personally identifying number
- Any file whose name suggests it is private (e.g., resume, payroll, tax)

Use a `.gitignore` filter and review every commit's diff before pushing.
When unsure, treat it as private.

## Reporting

If you spot information here that should not be public, open an issue at
<https://github.com/rockyzl/lu-zhang-site/issues> or email the owner
directly. We will remove and rewrite history as appropriate.
