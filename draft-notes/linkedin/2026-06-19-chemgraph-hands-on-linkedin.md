## Main Post

I ran ChemGraph locally because I wanted to see something simple:

Can a scientific agent show enough of its work for another person to trust the
answer?

I asked small chemistry questions first:

- methane combustion enthalpy
- water IR
- glucose dipole moment

The useful failures were not exotic. One saved run had no assistant answer. One
reaction run had useful data that the UI did not show. A later glucose question
could still be affected by older methane context.

That is where scientific agents become interesting to me. The hard part is not
only generating an answer. It is keeping molecule, method, result, and final
claim connected.

I wrote up the hands-on run here:

https://sciencesloop.com/blog/2026-06-13-chemgraph-scientific-agent-test/

My practical takeaway: before a scientific agent gives a number, it should show
what it ran, what came back, and when it should not answer yet.
